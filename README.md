# Portafolio — Leandro Rubio

Sitio personal para mostrar mis proyectos como desarrollador backend.

## Contexto
Portafolio personal, construido para centralizar mis proyectos y mi CV en un solo lugar.

## Demo
[Ver Demo](https://leandrorubio-73456.github.io/portafolio/)

## Stack Tecnológico
- HTML5 semántico
- Tailwind CSS (vía CDN)
- Diseño responsive (mobile-first)

## Características principales
- Sección de proyectos con enlace directo a cada repositorio
- CV descargable en PDF
- Meta tags SEO y Open Graph para compartir en redes/LinkedIn

## Estructura

```
├── index.html
└── assets/
    ├── favicon.svg / favicon.ico / apple-touch-icon.png
    ├── curriculum.pdf
    └── og-image.png
```

## Instalación

No requiere build. Abre `index.html` directamente, o sírvelo con:

```bash
npx serve .
```
